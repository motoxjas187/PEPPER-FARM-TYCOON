# 🌶️ Pepper Farm Tycoon

Idle conveyor-farm game for Android. Grow peppers from Bell to Experimental, route them with belts, sort them, feed customers, cross-pollinate new varieties and fight off bacteria.

## Get the APK
Go to **Releases** (right side of the repo page) → open the newest build → download `PepperFarmTycoon.apk` → open it on your phone and allow "Install unknown apps" if asked.

Every push to `main` builds a new APK automatically (Actions tab → **Build APK**). You can also run it by hand from the Actions tab with **Run workflow**.

## Updating the game
The game is one file: `app/src/main/assets/index.html`. Replace it and push. The new build installs over the old one and keeps your save.
